# AgentOS Runtime v1.0.0

## Overview

AgentOS Runtime v1.0.0 is the first stable release of a lightweight, modular LLM agent runtime.
It exposes the mechanics of planning, tool execution, memory, model adaptation, observation, and
evaluation through small typed interfaces instead of a monolithic agent framework.

The release also establishes an adapter boundary for MiniLLM-Serve and structured multimodal NPC
interactions. AgentOS can therefore sit between an application or Unity-facing protocol and a
replaceable inference backend without coupling the runtime core to either system.

## Features

- **Agent Runtime** — bounded async execution loop with explicit state and decisions
- **Model Adapters** — abstract model interface, deterministic fake model, and cached model wrapper
- **MiniLLM Integration** — HTTP adapter with configuration and normalized transport errors
- **Tool Calling** — registry, executor, serializable observations, and safe calculator tool
- **Memory** — abstract store, versioned JSON adapter, atomic writes, and NPC interaction state
- **Observability** — isolated runtime events, JSON traces, and latency profiling
- **Benchmark** — deterministic cases, trace-based metrics, and Markdown reporting
- **Performance** — response caching, timeout controls, and performance reports
- **Multimodal NPC** — perception, interaction, action, and privacy-conscious memory adapters

## Architecture

AgentOS follows a ports and adapters design. The agent core coordinates planner decisions while
depending only on abstract model, tool, and memory contracts. MiniLLM-Serve, JSON persistence,
trace storage, caches, and NPC protocol objects are replaceable boundary adapters. Observability
is a side channel: handler or trace failures do not redefine the main execution path.

```text
User / Unity / Multimodal Input
              |
      Interaction Layer
              |
        Agent Runtime
              |
           Planner
              |
       Model Interface
              |
       Tool / Memory
              |
     Trace / Evaluation
```

For the detailed component view, read [`docs/architecture.md`](../docs/architecture.md).

## Demo

Install the development environment:

```bash
python -m pip install -e ".[dev]"
```

With a compatible MiniLLM-Serve endpoint configured in
[`configs/default.json`](../configs/default.json), run the calculator agent:

```bash
python examples/calculator_agent.py
```

Run the local protocol and spatial interaction demonstrations without Unity or sensor hardware:

```bash
python examples/npc_bridge_demo.py
python examples/spatial_agent_demo.py
```

See the [examples guide](../examples/README.md) for prerequisites and expected output.

## Benchmark

The committed deterministic benchmark contains 10 cases and produced the following existing report:

| Metric | Result |
| --- | ---: |
| Cases | 10 |
| Success Rate | 100% |
| Average Latency | 0.0897s |
| Average Model Calls | 2.00 |
| Average Tool Calls | 1.00 |

These figures describe the local deterministic benchmark setup; they are not claims about remote
model quality or production serving latency. Reproduce the reports with:

```bash
python -m benchmarks.evaluator
python -m benchmarks.performance
```

- Additional tool adapters for search, code execution, and vision

- A live Unity transport implemented outside the AgentOS core

Roadmap entries are directional and are not part of the v1.0.0 API promise.
